# Ledger

In-memory account ledger core: value-dated entries, authorisation holds, overdraft fees, daily interest. 
Built using core java with JUnit 5.

## Run

```
./gradlew test
```

## Toolchain

Built on JDK 25, compiled with `--release 21`. Runs on any JDK 21 or later. The Gradle wrapper is committed, so no Gradle install is needed.
